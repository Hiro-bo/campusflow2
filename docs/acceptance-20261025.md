## 仍存在的问题

1. 正式网页输入“本次活动取消，请勿参加。”仍生成定时活动候选，缺少取消或禁止行动的显著提示。候选需要人工确认，但规则对否定含义处理不足。
2. 本地规则输入“2026年10月28日中午12:30参加会议。”只保留2026-10-28，时刻丢失，未说明丢失了原文时刻。
3. 本地规则输入“2026年10月28日14:00-16:00上课。”归为todo，未提取结束时间，因而不能按活动检查冲突。
4. “报名截止2026年10月28日，活动于2026年10月29日开始。”只有一项待确认候选，需人工拆分。当前编辑界面没有专门的拆分按钮，可通过新建任务补充。
5. 合成演示样例日期固定在10月23日和24日，当前会显示已过期；这是样例维护问题，不是过期判断故障。

本轮记录问题，没有修复上述规则。建议优先改取消/否定提示和课程时间识别，再补回归用例。真实在线模型、iPhone及Windows真机、实际日历导入仍待验收。
