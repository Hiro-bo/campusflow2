# 知行 CampusFlow 静态作业版

用于杭州电子科技大学 AIGC 应用创新大赛的校园通知整理原型。输入通知后，通过本地规则或可选在线 AI 提取候选，核对原文后逐项保存，再管理状态与导出日历。

## 部署与运行

发布仓库为 Hiro-bo/campusflow2。GitHub Settings → Pages → Source 选择 GitHub Actions。提交 main 后由现有工作流测试、构建并发布。网站无需自建服务器。

安装兼容的 Node.js 后运行 npm install、npm test、npm run build:pages。用 npm run preview:pages 预览生成的静态网页，不要直接双击 dist/index.html。

## 数据与 AI

任务和操作记录存于当前浏览器，使用 JSON 备份迁移。清理网站数据会丢失任务，不同浏览器不会自动同步。演示通知为合成数据。

快捷提取使用本地规则。在线 AI 由浏览器直接请求用户配置的模型接口，会向该地址发送通知正文及用于认证的 API Key。先确认地址可信并勾选发送通知的同意选项。API 服务可用性、模型支持、浏览器跨域限制及费用由所选服务决定。也可复制提示词到外部 AI 后导入 JSON。

密钥默认仅存在当前页面内存，刷新后需重新填写。明确勾选“记住密钥”并保存后才写入浏览器本地，同源脚本可能读取它，公共设备不要勾选。旧版保存的密钥不会自动载入，需要选择“载入旧密钥 仅本次”或清除旧配置。取消记住会移除保存的密钥，清除配置会同时重置密钥、模型、地址与连接状态。任务备份及操作日志不包含配置密钥。

填写密钥不代表接口已验证，只有连接测试成功才显示通过。修改地址、模型或密钥会使此前的测试结果失效。自动测试使用模拟响应，不调用真实付费 API。

## 日历与功能边界

“导入本地日历”生成兼容 iPhone/Outlook 的 ICS。截止事项为标有“【截止】”的日历事件，日期未明确的任务和已完成项跳过。可以选择为明确时刻的事项写入提前提醒，能否通知由日历软件权限与支持决定。

ICS 是一次性快照，网站后续修改不会自动更新已导入的副本，重复导入可能产生重复事项。JSON 才是完整任务备份。静态作业界面不开放持续订阅配置。仓库保留的 Node 后端与订阅源码不代表已经部署，当前交付不依赖这些接口。

没有群消息读取、OCR、网站后台推送、循环课表或任务双向云同步。相对日期以通知发布日期为基准，明确的本周/上周/下周采用周一为周首，含糊的无前缀星期保留待核查。AI结果必须人工核查，引用命中不代表理解正确。
